# ee
## 一款简易的运算表达式计算器

### 构建
```
$ mkdir build
$ cd build
$ cmake build ..
$ make && make install
```

### 运行
```
$ ee #交互式运行
$ ee -e "1+1" #带表达式参数运行
```
